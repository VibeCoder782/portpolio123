Case 02 동아대학교 교내 홈페이지 고도화 · 아리모아 · 2023.05 – 2023.11

오래된 관리표를 바꿔,팀의 진행을 한눈에.

약 200개 교내 사이트를 고도화하는 프로젝트에서 내부 PL을 맡았습니다. 여러 프로젝트로 바쁜 와중에도 회사의 기존 Google Sheets 관리표를 개편해 업무 진척을 한눈에 파악하도록 했습니다. 선임 PM은 발주처와의 주요 소통을, 저는 서비스기획과 내부 작업·일정·검수·협업을 맡았습니다.

기간
약 7개월 · 2023.05 – 2023.11
팀
약 10명 — 선임 PM · 기획 · 디자인 · 퍼블리싱 · 개발
내 역할
내부 PL — 서비스기획 · 작업현황 · 일정 · 검수 · 협업
범위
대표 홈페이지를 포함한 교내 사이트 약 200개 고도화 · 기존 콘텐츠 이관
지금
donga.ac.kr 운영 중 · 1차 오픈 약 100개

01

바쁜 와중에도 바꿔야 했던 관리 방식

여러 프로젝트가 병행되며 인력이 나뉘었고, 제작 완료가 늦어지는 데다 완료됐는지도 공유되지 않았습니다. 완료를 모르니 검수를 시작할 수 없고, 검수가 늦으니 수정이 늦고, 오픈 일정이 연쇄로 밀릴 위험이 있었습니다.

기존 Google Sheets 관리표는 작업 목록 위주여서 담당자별 진척과 검수 여부, 남은 일을 한눈에 파악하기 어려웠습니다. 바쁜 일정을 그대로 따라가기만 해서는 이 문제가 반복된다고 보고 관리 방식을 개편했습니다.

02

보이게 만들고, 순서를 정하다

기존 Google Sheets 관리표를 새로 구성해 담당 · 마감일 · 제작 상태 · 검수 상태 · 수정 요청 · 오픈 우선순위가 한 화면에 보이도록 정리했습니다. 담당자별 미완료 항목을 수시로 확인하고, 전체 일정과 오픈 우선순위를 반복해서 조정했습니다.

완료되는 사이트부터 즉시 검수하고, 오류를 정리해 전달 → 수정 → 재확인을 반복했습니다. 고객 자료가 늦는 항목 중 오픈 뒤 처리해도 되는 범위는 선임 PM과 함께 발주처와 후속 범위로 협의했습니다. 팀의 업무 상황을 살피며 우선순위를 조율하고, 현재 상태와 다음 행동을 함께 확인할 수 있도록 했습니다.

Sheet 작업·검수 관리표 — 한 화면에 담당 · 상태 · 검수 · 오픈 순서

03

완료되는 것부터, 끝까지

1차 오픈으로 약 100개 사이트를 열었고, 남은 항목은 발주처와 합의한 후속 범위로 이어졌습니다. 기존 콘텐츠는 이관 범위에 포함해 함께 옮겼습니다.

이 프로젝트에서 배운 것은, 규모가 커질수록 기획의 일은 화면을 그리는 일보다 팀이 같은 기준으로 움직이게 하는 일이 된다는 것입니다.

Now 지금 운영 중인 화면 — 약 200개 중 둘

donga.ac.kr 운영 화면 · 파란 밑줄은 포트폴리오 표시

Result 결과와 배운 점

  1. 1차 오픈
    약 100개 사이트의 1차 오픈을 진행했습니다.

    완료되는 사이트부터 검수하고 수정·재확인을 반복해 연 결과입니다. 남은 항목은 후속 범위로 이어졌습니다.

  2. 관리 방식
    작업 → 검수 → 수정 → 재확인 흐름과 관리표가 팀의 공통 기준이 됐습니다.

    담당 · 상태 · 검수 · 잔여 작업을 한눈에 파악하게 되면서 작업을 더 빠르게 이어갈 수 있었습니다.

  3. 배운 것
    사람을 밀어붙이기보다, 현재 상태와 다음 행동을 계속 보이게 한다.

    이후 핸디에서 협업 운영 방식을 설계할 때도 같은 원칙에서 시작했습니다.
