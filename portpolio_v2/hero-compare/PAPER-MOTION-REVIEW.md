## 구현

- 기존 목록·본문·이미지 자리와 히어로 3D 정렬을 유지. 사진만 Three.js의 격자 평면과 셰이더로 그린다.
- 등장 약1.08초: 아래에서 올라오며 표면이 휘었다 펴진다. 이전 이미지 퇴장 약0.72초: 위로 이동하며 휘고 사라진다. 빠른 재선택은 현재 상태에서 다음 목표로 이어진다.
- 대기: 약6.16초 주기의 느린 휨. 중앙보다 좌우·아래 가장자리가 움직인다. 아르피나는 다른 사진보다 약하다. 포인터 기울기는 X축 최대 약1.7도, Y축 약2.1도. 모바일은 휨 강도55%, 포인터 기울기 없음.
- 이미지를 자르는 위치와 안내문·출처·상세 링크는 유지. 원본 파일을 편집하지 않고 런타임 텍스처에 동일한 표시 영역을 그린다.
- 사진 움직임 버튼을 누르면 원본 이미지로 돌아온다. OS 동작 줄이기도 원본 표시. WebGL 초기화/실행 실패·컨텍스트 손실 시 원본 표시로 복구한다.
- 갤러리에 가까워지면 Three.js를 불러온다. 캔버스는 하나이고 DPR 상한1.5. 갤러리가 화면 밖에 있거나 탭이 숨겨지거나 움직임을 끄면 렌더 루프를 멈춘다.
- Three.js 0.186.0 공식 npm 패키지 무결성 확인 후 필요한 로컬 모듈2개와 MIT LICENSE만 보관. 경로 `shared/vendor/three-0.186.0/`. 모듈 원본 합계2,120,885바이트, CDN 요청·외부 API·물리 엔진 없음. 현재 로컬 정적 서버에서 압축되지 않은 크기이며 배포 번들 최적화는 수행하지 않았다.
