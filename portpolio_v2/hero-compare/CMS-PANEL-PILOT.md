# 04 입체 패널 시안

사용자 승인: 04에 입체 패널 등장 + 약한 마우스 반응. 05·06 및 본문 배치는 유지.

## 구현

- 로컬 Three.js r186 재사용. 신규 설치나 외부 API 없음.
- 기존 정적 이미지를 하나의 얇은 판의 표면으로 사용. 내부 UI 패널을 분리하거나 이미지 자체를 수정하지 않음.
- 약 10도 기울어진 두 축의 각도와 앞쪽 깊이를 1.1초에 걸쳐 정면으로 복귀. 부드러운 접촉 그림자가 정착에 맞춰 변함.
- 마우스 반응 최대 약 2~2.6도. 원본 색상은 기본 재질로 유지하고 은은한 표면 빛만 별도로 겹침.
- 마우스가 나가면 정면 복귀. 정착 후 프레임 예약을 종료. 화면 밖/숨겨진 탭에서는 렌더링 중지. 모바일은 등장 각도를 줄임.
- 원본 img의 alt와 상세 링크 유지. WebGL 실패/컨텍스트 손실, 움직임 줄이기, 인쇄 시 원본 정적 이미지 표시.
- `review=cms-panel...` 주소에서만 '효과 다시 보기' 버튼과 렌더 진단 속성 제공. 일반 포트폴리오 주소에는 검토 버튼 없음.
- 이전 CSS 이미지 등장 효과는 교체. 표의 구분선 효과 유지.

## 검증

- build.sh 및 JS 구문 검사 성공.
- 1280px: WebGL canvas 1개, 원본 이미지의 대체 표시 확인, 브라우저 오류/경고 없음.
- 다시 보기 클릭: 실제 렌더 각도 약 -0.136rad / 깊이 18.606 → 정면 0 / 깊이 0 확인.
- 포인터 이동: 실제 각도 0.019 / 0.040rad → 포인터 이탈 후 0 / 0 확인.
- 정착 후 두 번의 조회에서 렌더 수 447 유지: 유휴 반복 렌더링 없음 확인.
- 390px: 가로 넘침 없음. 제목·검토 버튼·이미지 배치 시각 확인, 이미지 정상 표시.
- OS 움직임 줄이기 전환, 컨텍스트 손실, 인쇄는 코드 경로 확인만 수행. 실제 모바일 기기 성능은 미측정.
