# 04 등장 효과 시범 적용

후속: 이미지의 CSS 등장 효과는 [CMS-PANEL-PILOT.md](CMS-PANEL-PILOT.md)의 Three.js 패널로 교체됨. 아래는 이전 검토 기록.

승인 범위: 04에 먼저 적용해 강도를 확인하고 05·06 확장 여부 논의.

- 이미지 전체가 12px 아래에서 0.75초 동안 선명해지며 등장. 모바일 6px. 패널 개별 움직임, 반복, 스크롤 고정, 추가 공간 없음.
- 표의 구분선은 0.65초에 걸쳐 그려지며 두 행의 시작 차이는 0.15초. 표의 글자·제목·본문 고정.
- 기존 IntersectionObserver를 사용해 이미지/표가 각각 보일 때 한 번 실행하고 관찰 해제. lazy 이미지 준비 후 등장. 움직임 줄이기와 인쇄 시 기존 정적 폴백 유지.
- 05·06 및 프로필 효과는 이번에 확장하지 않음.

검증: 빌드·JS 구문 검사 성공. 1280px에서 이미지 대기 opacity 0 / translateY 12px → 완료 opacity 1 / translateY 0 확인. 실제 중간 캡처에서 구분선 길이 차이 확인. 06 이동 후 04 복귀 시 완료 상태 유지. 390px에서 이동 설정 6px, 넘침 없음, 본문 opacity 1. 오류 로그 없음. OS 움직임 줄이기 설정 전환은 실측하지 않았으며 코드 경로 확인만 수행.

확인: http://localhost:8790/hero-compare/sans.html?review=cms-arrival-v1#row-cms
같은 페이지에서 위아래 이동해도 반복하지 않으므로 재확인은 새로고침 후 진행.
