## 실제 검증

- `build.sh` 실행 성공. 생성된 sans/serif와 상세의 CSS/JS 캐시 버전 갱신.
- 두 JS 파일 `node --check` 통과.
- 메인 2개와 상세 6개에서 로컬 링크·이미지·앵커 존재 여부, 중복 ID, H1 개수 점검: 오류 없음.
- 보존본 16개 SHA-256 재검증: 일치.
- Codex 내장 브라우저 1280×720에서 히어로 → 정렬 → 첫 사례로 전진·역방향 스크롤 확인.
- 대표 사례 버튼 클릭 시 첫 사례 상단 0px, 고정 컨테이너 내부 scrollTop 0. 숨김 컨테이너가 브라우저에 의해 스크롤되던 현상은 `overflow: clip`으로 수정.
- 상세 상단 Work와 아르피나 상세 하단 복귀 링크가 대표 사례로 이동하는 것을 실제 클릭으로 확인.
- 390×844: 메인·상세 6건 가로 넘침 없음. 메인의 대표 사례 이동 시 첫 사례 상단 64px, 내비게이션 높이 64px, 종이색 배경 적용.
- 320×568에서 메인 가로 넘침 없음. 1440×900 메인 가로 넘침 없음.
- 1280×600 낮은 창에서 고정 연출을 끄고 자연 스크롤로 읽힘. 대표 사례 이동 시 내비게이션 아래 72px에 도착.
- 동아대 모바일 관리표: 표 영역 350px / 내용 600px, 표 안에서만 가로 스크롤, 키보드 접근 가능한 region 확인.
- 영수증 열기·접기 실동작과 8/6/8건 목록 보존 확인. 반복 흔들림 제거.
- 상세 6건 데스크톱·모바일 로드 확인. 관찰한 콘솔 오류·경고 없음, 깨진 이미지 없음. Arpina/Google Sheets/Jira/이음 등 설명·이미지 배치를 스크린샷으로 확인.
- 모바일 Contact의 이메일·QR·오픈채팅 직접 링크 배치 확인. 외부 메시지 전송은 하지 않았다.

## 검증 한계

- 동작 줄이기·스크립트 비활성화 대체 경로는 코드/CSS 검토 범위다. OS 설정을 바꾼 실기 검증이나 스크립트 차단 브라우저 검증은 하지 않았다.
- Safari·실제 iPhone/Android 기기에서의 검증은 하지 않았다. 웹 브라우저 화면 크기 조절 결과와 구분한다.
- 캡처는 기존 제공 자산이다. 이번 작업에서 외부 사이트의 최신 화면을 다시 촬영하지 않았다.
- 상지 전체 계약 기간과 실무 참여 기간의 정확한 월별 관계는 추가 확인 전이다. 확인되지 않은 종료 월을 만들지 않았다.
- 이력서 PDF 자체는 수정하지 않았다. 이번 실행 범위는 포트폴리오 프론트다.
- 로컬 구현이며 배포·push·Claude 외부 전달은 하지 않았다.
